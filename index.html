05. Open Source

zephyrproject-rtos/zephyr

drivers: i2c: stm32: ignore spurious BERR in controller mode

Merged

Debugged a spurious Bus Error (BERR) flag raised by STM32 I2C V1/V2 peripherals during controller-mode operation — a behavior documented across multiple STM32 errata sheets. Implemented a driver-level fix that clears the false BERR flag without aborting the transfer, while preserving genuine error reporting in target mode. Landed in both i2c_stm32_v1.c and i2c_stm32_v2.c.
